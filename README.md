# Machine Learning Practicals

This folder contains separate, concise, and easy-to-understand Python implementations for all 9 machine learning practicals.

## List of Practicals

1. **[practical_1.py](practical_1.py)** — Data Preprocessing Techniques (Data Cleaning, Transformation, Feature Encoding & Scaling).
2. **[practical_2.py](practical_2.py)** — Regression-Based Machine Learning Model (Linear Regression using Diabetes dataset).
3. **[practical_3.py](practical_3.py)** — Logistic Regression for Classification (Iris dataset).
4. **[practical_4.py](practical_4.py)** — Spam Email Classification using Naïve Bayes.
5. **[practical_5.py](practical_5.py)** — Decision Tree-Based Classification (Breast Cancer dataset with evaluation metrics).
6. **[practical_6.py](practical_6.py)** — Unsupervised K-Means Clustering & Silhouette Score Evaluation.
7. **[practical_7.py](practical_7.py)** — Apriori Algorithm (Frequent Itemsets) & Outlier Detection (Isolation Forest).
8. **[practical_8.py](practical_8.py)** — Neural Network Activation Functions Plotting (Sigmoid, ReLU, Tanh).
9. **[practical_9.py](practical_9.py)** — McCulloch-Pitts Neural Net for ANDNOT Function.

## How to Run
Run any practical using Python from the root directory:
```bash
python "ml practicals/practical_1.py"
```
Or navigate into the folder:
```bash
cd "ml practicals"
python practical_1.py
```
